Summary
  This project explores the relationship between the Federal Funds Rate (FEDFUNDS) and the S&P 500 Index (SP500), two of the most widely referenced indicators of U.S. macroeconomic and financial market conditions. The motivation behind the project comes from our passion for the financing world and industry as we are both Finance majors with concentrations in Data Science. The economic question we aim to answer is: How does the Federal Funds Rate influence movements in the S&P 500 index over time, and can interest rate changes be observed in subsequent market behavior?
  Understanding the relationship between monetary policy and equity markets is important for policymakers, economists, financial analysts, and the investing public. Interest rates affect the cost of capital, corporate investment, consumer borrowing, and overall economic activity. Meanwhile, the stock market is often regarded as a forward-looking reflection of expectations about growth, risk, and profitability. By exploring data trends from 2000–2024, we want this project to contribute to a transparent, reproducible understanding of how these variables move together.
  Our workflow follows the core philosophy of IS477: reproducibility, transparency, structured curation, and documentation. The project includes data acquisition, quality assessment, cleaning, exploratory analysis, visualization, and workflow automation. All data is sourced programmatically from FRED (Federal Reserve Economic Data) using documented APIs, ensuring that others can fully replicate the process. Because FRED data is open-access but subject to redistribution policies, our repository includes scripts for acquiring data but does not redistribute the source data directly. Instead, we provide a Box folder containing processed output data derived from our analysis. Instructions for accessing and placing these files are provided under the Reproducing section.
  The analysis process included profiling both datasets, validating metadata, evaluating missing data, standardizing time formats, and aligning observation dates. After cleaning and integration, we calculated summary statistics, correlation values, and time-series visualizations to explore whether patterns could be meaningfully observed. We had a special interest in whether increases in the Federal Funds Rate correspond to declines in the S&P 500. This would be consistent with economic theory that is taught in the Gies College of Business at UIUC suggesting that tightening monetary policy places downward pressure on asset prices.
  The initial results indicate that the relationship between FEDFUNDS and the S&P 500 is not strictly linear, but general patterns emerge. For one, extended periods of low or declining interest rates tend to coincide with upward market trends, sharp rate increases often align with periods of market contraction or volatility, and correlation analysis shows a moderate negative relationship over the full sample period.
However, interpretation must consider confounding variables such as global economic shocks, technology cycles, geopolitical events, and sector-level performance. The workflow created for this project aims to be automated or documented through Python scripts and a Snakemake workflow. A Run-All script ensures that someone can reproduce results in a single execution command, assuming dependencies are installed. Metadata files, a data dictionary, and a structured folder hierarchy offer additional transparency.
  Ultimately, our findings support the broader economic understanding that monetary policy influences financial markets, but not in a deterministic or perfectly predictable way. Instead, interest rates act as one key driver within a complex system. Our project contributes a reproducible analytical foundation for understanding this relationship, with opportunities for future work addressing seasonality, lag structures, predictive modeling, and expanded macroeconomic variables (which will be touched on in the conclusion).
  
Data Profile
  This project uses publicly accessible macroeconomic and financial datasets from the Federal Reserve Economic Data (FRED) system. Each dataset comes in CSV format and is later processed into an analytical panel made to compare Federal Reserve interest rate policy and U.S. stock market performance. The central dataset used in this project is the Effective Federal Funds Rate (FEDFUNDS), which represents the interest rate at which depository institutions lend balances to one another overnight. This rate - which is widely considered the Federal Reserve’s primary monetary policy tool - has significant influence on credit markets, corporate investment decisions, and broader economic conditions. The raw FEDFUNDS dataset has daily observations containing a date field and a value column labeled "FEDFUNDS." To make sure there was comparability across indicators, the data was resampled into monthly averages to smooth out daily fluctuations. The data presented no ethical concerns, as it includes no personal information or sensitive variables. Legally, redistribution of the raw data is discouraged under FRED’s usage policy, so the raw file is not committed to GitHub; instead, we have provided the code and instructions necessary to re-obtain the dataset directly from FRED.
  The second core dataset is the S&P 500 Index (SP500), also sourced from FRED. This index represents the performance of 500 large publicly traded U.S. companies and serves as a widely used benchmark of the overall U.S. equity market. Like FEDFUNDS, the SP500 dataset provides daily values, which we converted to end-of-month closing levels to match the monthly time scale used in our analysis. The dataset consists of a date column and the corresponding index value. As with FEDFUNDS, we do not redistribute the raw SP500 data but instead document how to obtain it programmatically or manually. There are no ethical concerns associated with this dataset either, as it contains no human-related information. Legally, the underlying S&P 500 index is proprietary, but FRED's historical series is permissible for academic use.
  In addition to these primary series, the project includes supplementary datasets: the Federal Funds Target Rate upper and lower bounds (DFEDTARU and DFEDTARL) and the CBOE Volatility Index (VIXCLS). These datasets provide more context about monetary policy and market expectations. DFEDTARU and DFEDTARL reflect the Federal Open Market Committee’s policy target range for the Federal Funds Rate, and their inclusion allows for the comparison of actual effective interest rates with their target boundaries. The VIXCLS dataset provides information about expected market volatility using options pricing, which can serve as an indicator of investor uncertainty. These datasets, when available, were incorporated into the analytical panel after being resampled to monthly averages. Like the primary datasets, they contain no sensitive information and follow FRED’s redistribution guidelines.
  All datasets, once cleaned, were integrated into a single consolidated analytical file titled ‘monthly_panel.csv’. This panel forms the foundation for all subsequent analysis. It includes monthly interest rate levels, month-to-month rate changes, S&P 500 closing values, realized volatility computed from daily returns, monthly market returns, and forward-looking returns over one, three, and six-month horizons. It also includes fields such as the target rate bounds and VIX, as well as derived indicators such as whether interest rates are above the sample median and whether rates are rising. This integrated dataset is a derived work created entirely within the project’s workflow. Since it contains only aggregated economic indicators, it carries no ethical or privacy considerations. Furthermore, because it is derived rather than directly redistributed from FRED, it is permissible to include within the project’s Box folder for reproduction, provided that FRED is properly cited.
  
Data Quality
  Data quality was a central focus of this project, as economic and financial analyses rely heavily on accurate, consistent, and well-structured time-series data. The initial quality assessment involved examining each raw dataset for missing values, outliers, duplicates, and format inconsistencies. Both FEDFUNDS and SP500 had expected patterns of incompleteness due to weekends, holidays, and market closures. For example, financial markets do not operate on weekends or federal holidays, and the Federal Reserve does not publish daily data for certain series. However, because the analysis ultimately uses monthly data, these missing daily records did not impair the integrity of the dataset. Instead, we addressed this by aggregating all datasets to a monthly frequency, using the mean for FEDFUNDS and the end-of-month value for SP500. This aggregation both simplifies the dataset and increases its usability for higher-level economic comparisons.
  We also conducted consistency checks to ensure that all variables adhered to correct data types and realistic value ranges. Dates were converted into standardized datetime formats to allow proper time-series operations such as indexing, sorting, and resampling. Any non-numeric anomalies - for instance, "." representing missing values - were made into numeric types and dropped when necessary. The value ranges for FEDFUNDS and SP500 aligned with historical records, confirming that the datasets had not been corrupted or distorted. FEDFUNDS values remained within plausible historical bounds, and SP500 levels reflected major market events such as the dot-com decline, the 2008 financial crisis, and the 2020 COVID-19 crash and rebound.
  Temporal alignment presented another crucial part of data quality. Since the datasets originated from sources with different reporting conventions and frequencies, a merge would have resulted in mismatched or duplicated records. For instance, FEDFUNDS publishes rates daily, while SP500 publishes market closes on trading days only. To align these datasets, we standardized all series to monthly timestamps, resampling them with clearly documented methods. This approach created a consistent time-indexed dataset that eliminates temporal gaps and aligns economic indicators and market outcomes on the same schedule. Once aligned, the datasets merged cleanly with no duplicates or inconsistencies.
  Data enrichment steps such as computing realized volatility and forward-looking returns were also subject to quality validation. Realized volatility was calculated as the standard deviation of daily returns within each month, which required first ensuring that the daily returns were properly computed and that no missing daily pricing data created artificial distortions. Forward-looking returns required checking that all values were aligned appropriately with future timestamps; forward returns at the end of the dataset naturally contain missing values, which were later excluded from analysis to avoid misleading artifacts.
  The final data quality verification involved reasonableness checks through visualization. Graphical inspection revealed patterns fully consistent with known economic history: spikes in volatility during crises, falling interest rates during recessions, and extended periods of low interest rates following the 2008 recession. This alignment with historical narratives further reinforced confidence in the validity and integrity of the cleaned dataset. Overall, the data quality process ensured that the integrated panel dataset was accurate, consistent, logically structured, and analytically reliable.

Findings 
  The findings of this project center on the relationship between the Federal Funds Rate and the performance of the U.S. stock market, represented by the S&P 500 Index. After constructing the monthly analytical panel, descriptive statistics revealed several important characteristics of the economic and financial environment over the 2000–2024 period. Interest rates spent long periods at historically low levels, particularly following the 2008 financial crisis and again after the COVID-19 pandemic, while the S&P 500 saw substantial long-run growth despite several severe downturns during crisis periods. Volatility behaved as expected, with pronounced spikes during recessionary or high-uncertainty environments.
  Correlation analysis revealed a moderately negative relationship between the level of the Federal Funds Rate and the S&P 500’s monthly closing values. This suggests that higher interest rates tend to correspond with lower market levels, a finding consistent with economic theory: when borrowing becomes more expensive and expected future cash flows are discounted at higher rates, equity valuations generally fall. Rate changes also showed negative association with future returns, meaning that months with rising rates tended to precede periods of weaker market performance. Although correlation does not imply causation, the observed patterns align closely with macroeconomic intuition - like we mentioned above - consistent with the teachings of Gies Business School.
  Visual analysis provided intuitive support for these quantitative findings. The dual-axis time-series plot of SP500 and FEDFUNDS illustrates clear periods where rate hikes coincide with market slowdowns or volatility increases. For instance, the tightening cycles of the early 2000s, mid-2000s, and post-2022 period all correspond with visible declines or instability in the S&P 500. Conversely, extended low-rate environments such as the post-2008 recovery and the pre-pandemic expansion correspond with long market uptrends. The scatterplot of interest rates versus index levels shows a discernible downward-sloping cloud, reinforcing the negative relationship in a non-time-based view.
  These findings point to a clear conclusion: interest rates are a meaningful driver of equity market behavior. When monetary policy tightens, markets tend to experience downward pressure, while accommodative policy generally supports growth. At the same time, the relationship is far from perfect, and the remaining unexplained variance reflects the influence of global events, technological developments, corporate earnings cycles, and investor sentiment. The results confirm that interest rates are best viewed as a key component within a broader, multifactor economic system. Nonetheless, the reproducible workflow developed here makes these relationships transparent and easily extensible for more advanced modeling.
  
Future Work
  Although this project provides a strong foundation for understanding the relationship between interest rates and stock market performance, options exist for expanding the analysis. One direction could involve exploring lagged relationships more systematically. Our preliminary examination suggests that the effects of rate changes may not exist fully in the same month, and future studies could examine distributed lag models or conduct formal Granger causality tests to evaluate whether and how interest rate movements help predict future market behavior.
  Another valuable extension would involve incorporating additional economic indicators. The macroeconomic environment is shaped by many factors beyond interest rates, including inflation, unemployment, consumer spending, industrial output, and fiscal policy. Introducing variables such as CPI, unemployment rates, Treasury yields across maturities, or credit spreads could enable more sophisticated models capturing interactions between variables. This expansion would allow researchers to distinguish the independent effect of monetary policy from other macroeconomic forces driving market outcomes.
  Methodologically, future work could incorporate advanced machine learning techniques. Vector autoregression (VAR) models could capture multi-directional relationships among several economic variables, while other models could help identify structural differences between high-volatility and low-volatility market conditions. Machine learning models such as random forests, gradient boosting, or recurrent neural networks could explore nonlinear relationships and possibly uncover predictive patterns, though whoever is doing this must be careful to avoid overfitting in financial contexts.
  In terms of volatility, the project could be enriched by deeper analysis of both realized and implied volatility measures. For example, incorporating GARCH models would allow the study of volatility persistence, clustering, and the asymmetric effects of economic shocks. Such models could help explain why markets respond differently to rate changes under varying conditions.
  From a workflow and data engineering perspective, several improvements could enhance reproducibility and scalability. Although this project uses a Jupyter notebook as the primary execution environment, future iterations could incorporate a full Snakemake workflow with detailed dependency rules to automate every stage from data acquisition to visualization. Containerization using Docker could make sure there was consistency across computing environments, while publishing the project to Zenodo would produce a citable DOI and make the work more accessible to researchers.
  Finally, the project offers lessons about collaborative workflows. Technical challenges such as GitHub authentication issues can disrupt contribution tracking, but shared documentation, clear division of roles, and explicit contribution statements - as provided here - can help maintain transparency. Future teams may benefit from establishing workflows, access privileges, and repository structures earlier in the development process. Overall, this project highlights the importance of reproducibility for enabling future research.
  
Reproducing the Workflow
  Reproducing this project is straightforward because all steps are documented and implemented in a structured workflow. To begin, a user should clone the GitHub repository containing the project code, documentation, and directory structure. Once the repository has been downloaded locally, the user should install the required Python dependencies using the provided ‘requirements.txt’ file to ensure that all packages - including pandas, numpy, and matplotlib - are correctly configured. The next step involves obtaining the data. Users may either download the processed data shared in the project’s Box folder and place the files in their appropriate directories, or, if they wish to reconstruct the dataset from scratch, they may download the raw CSV files for FEDFUNDS, SP500, and the optional target rate and VIX series directly from FRED. These raw files should be placed in the project root, mirroring the structure used during development.
  After the data is in place, the user should open the main Jupyter notebook, titled ‘IS477 Milestone 03.ipynb’, and run all cells in sequence. The notebook performs every major step of the workflow, including loading and cleaning the data, resampling variables to monthly frequency, calculating monthly returns and volatility, generating forward returns, constructing regime variables, merging all data into a unified panel, computing summary statistics and correlations, producing visualizations, and writing the updated data dictionary. The notebook will also output all processed files into the appropriate directories, ensuring that the project remains consistent with the artifacts referenced in this report. This notebook functions as the “run-all” mechanism for the entire analysis and is sufficient for complete reproduction. Users wishing to explore deeper modifications or run individual scripts may consult the code contained within the project, but for the purposes of the course rubric, executing the notebook fully reproduces all results presented here.
